# My GeoDev Lab project. GIS-Based Cycling Route Optimization for Air-Quality Exposure in Stuttgart

## Overview

This project investigates cycling routes in Stuttgart that minimize exposure to air pollution, particularly nitrogen dioxide (NO₂). By combining air-quality data with cycling and road-network data, the project aims to identify cycling routes that provide healthier urban mobility.

Built over twelve months with GeoDev Lab Africa, Cohort One.
